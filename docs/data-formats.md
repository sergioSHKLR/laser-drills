# Data formats

## targets.json
```json
{ "template": {"...": "page sizes, margins, marker size"},
  "targets": { "<key>": {
    "code": "SD-01", "name": "…", "paper": "letter|tabloid",
    "markerIds": [0,1,2,3], "distance": "3 yd ≈ 13.5 yd sim",
    "zones": [ {"id":"A","shape":"circle|rect|poly","points":5, "...":"geometry in inches", "kind":"hit|nohit|cover|two|cond|head|backstop"} ],
    "scoring": "points|idpa", "layout": {}, "meta": {}, "metaOverride": {} } } }
```
Marker IDs are unique per target. Locking onto the markers identifies the sheet.

## drills.json
An array of drills:
`{id, name, category, target | targets[], shots, startDelay:[min,max], parTime, timeout, scoring?, maxPerShot?, notes}`.
Optional mode blocks are `sequence`, `calls`, `scenario` (shoot/don't-shoot with verbal commands), `crowd`, `game`, plus `voiceStart`, `startPos` and `shotgun`.
Multi-stage entries use `{type:'course', stages:[drill-like objects]}`.

## courses.json (generated by `tools_courses.py`)
```json
[{ "id":"nra-mm", "group":"Qualification ranks", "name":"…", "badge":"…", "icon":"award",
   "requires":"nra-pm", "notes":"…",
   "stages":[{ "name":"…", "drill":"<drill id>", "brief":"…", "dist":"7 yd → 1.5 yd laser",
               "set":{"shots":5,"parTime":3,"timeout":6,"target":"…"},
               "pass":{"minPct":80,"maxTime":3,"maxFinal":null,"noFail":true} }] }]
```
`icon` is a Lucide icon name from the inline sprite. A course is complete when every stage has at least one passing run for the active firearm.

## Run history (`ld.history`) and export
A run looks like this: `{id, t (ms epoch), fw (firearm id), drill, name, target, shots, hits, score, pct, time, final?, pd?, pe?, hnt?, fail?, splits[], course?, stage?, pass?}`.

- **JSON export:** `{app:"laser-drills", kind:"history", version, exported, firearms:[…], runs:[…]}`. Import either merges (duplicate runs are skipped by `id`) or replaces everything.
- **CSV export:** one row per run, with date, firearm, drill, score, time and course columns.

## Firearm profiles (`ld.firearms`)
`[{id, name, type:"pistol|rifle|shotgun|other", caliber, optic, suppressor, notes}]`. The active profile ID is stored in `ld.fw`.

## Other localStorage keys
| Key | Value |
|---|---|
| `ld.sae` | Score-at-end toggles (Self-Defense and Fun) |
| `ld.fr` | First Responders on or off |
| `ld.tick` | Shot tick |
| `ld.vf` | Viewfinder size and minimize setting |
| `ld-settings` | Detection calibration |
| `ld-zones` | Custom zones per target |
