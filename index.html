How it works
• Shoot tab: Start Camera, wait for the blue outline (target locked), then START. Random start beep, par time, auto-stop on shot count or time limit.
• Score at end (IDPA): Self-Defense drills hide hits until the string ends, then reveal hits, points down, PE/HNT, time and a spoken summary. Fun drills give live feedback (change in Settings).
• Voice: tap the mic and say start · stop · reset · next · repeat · score. Bluetooth media buttons and keyboard (Space start/stop, Esc stop) work too.
• Missed or false shots? Settings › Calibrate.
